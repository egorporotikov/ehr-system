EHR System Information

An Electronic Health Record (EHR) system helps doctors manage patient data, including:

  • Patient demographics (name, age, gender)
  • Medical history
  • Medications and allergies
  • Lab tests and radiology images
  • Vital signs (weight, age, last visit)
  • Billing information

This project demonstrates CRUD operations, image uploads, survey collection, and a responsive dashboard using Flask, Bootstrap, and SQLite/MySQL.
